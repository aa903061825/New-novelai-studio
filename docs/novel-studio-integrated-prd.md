# Novel Studio 三源整合落地版 PRD

## 一、概述

**文档信息**

| 版本号 | 日期 | 作者 |
|--------|------|------|
| V 1.0.0 | 2026-05-22 | 用户 |

### 1. 需求背景

- **目标用户现状**：目标用户是长期使用 NovelAI 做图像创作的个人用户，当前已经拥有可用成品和大量素材，但素材、Prompt 装配、生图执行、画师串整理、结果回溯分散在 `NAI CasRand`、`KAMIA prompt-studio`、`画师串工作室` 三套工具中。
- **核心痛点**：现有能力并不缺，但入口、数据模型和创作流彼此割裂。用户需要在不同工具间复制 Prompt、切换素材来源、手工回忆生成参数和结果来源，整合与 UI 优化如果只做新壳，反而容易把已有能力漏掉。
- **当前问题汇总**：

| 问题点 | 问题描述 | 当前影响 |
|--------|----------|----------|
| 三源数据分散 | CasRand 管生成与批量，KAMIA 管配方/Tag/角色，画师串工作室管画师串/过滤/排序工具 | 旧工具需要跨界面搬运数据，新工具必须在内部消化这层复杂度 |
| 工作流断裂 | 素材整理、Prompt 装配、单张生成、批量跑图、画廊回溯未形成同一闭环 | 结果能生成，但难以复盘、复用和持续积累 |
| 旧 UI 口径污染 | 临时 Novel Studio 壳出现小说章节口径，Health 被误放到用户设置路径 | 信息架构偏离真实产品目标 |
| 已有功能易遗漏 | CasRand 的高级生成参数、KAMIA 的素材增强能力、画师串工作室的翻译/排序/预设工具都可能在整合时消失 | 新版本表面更统一，实际能力倒退 |

### 2. 需求目标

- **业务目标**：
  - 把三套现有工具收敛为一个长期可用的本地 Prompt + 生图工作室，形成 `素材 -> 装配 -> 生成 -> 批量 -> 回溯 -> 再创作` 闭环。
  - 在整合过程中保留已有有效功能，并为每项能力明确产品归宿：页面入口、数据承载和流程位置。
  - 以真实数据流和已有生成能力为中心重做 UI，不迁移临时空壳，不让“看起来像工作室”压过实际工作效率。
- **成功标准**：

| 指标 | 当前状态 | 目标状态 |
|------|----------|----------|
| 三源能力归宿 | 能力分散，归宿依赖记忆 | 现有核心能力均在 PRD 中标注 `保留/合并/内部化/明确排除` |
| 单张创作闭环 | 需要跨工具装配与生成 | 在工作台完成素材选择、Prompt 预览、NAI 生成、画廊写回 |
| 批量创作闭环 | CasRand 可跑批量，但与素材库分离 | 批量产线可复用工作台资产和 CasRand 配置树 |
| 结果可回溯 | metadata 与素材引用未统一 | 画廊可查看 Prompt、参数、素材引用并送回工作台 |
| 用户可见导航 | 旧导航与临时壳混杂 | 一级导航稳定为 6 区，Health 不对普通用户露出 |

### 3. 需求范围

- **包含**：
  - 三源能力的内部归并、本地素材索引与来源追溯；这层实现不向用户暴露。
  - 素材库中的角色、Outfit、画师串、Prompt 配方、Tag、过滤规则、参考图、灵感素材、LoRA 元数据和工作流资产管理。
  - 工作台中的 Prompt 装配、手动编辑、草稿/预设/历史、单张生成和高级生成参数。
  - CasRand 批量产线、随机 Config 树、保存配置、导入导出、批次执行控制和生成环境设置。
  - 画廊、metadata 回溯、结果复用、筛选与再次创作入口。
  - 画师串工作室中翻译、标签拆分/分类、PNG metadata 排序/过滤/批处理、预设等辅助能力的产品归宿。
- **不包含**：
  - 账号登录、云同步、多人协作、在线社区。
  - 小说写作、章节管理、故事正文编辑等旧口径。
  - 普通用户可见的 `Health / 诊断` 页面入口；诊断仅保留为内部校验、日志和开发能力。
  - 直接复用临时 Novel Studio 空壳页面和旧 Playful Geometric 视觉结构。
  - 建议默认值：移动端专属交互和 Web 端发布不作为本版本验收前提，优先桌面端长期创作体验。

## 四、功能说明

### 功能 1：工作台方案导入导出

**功能描述**

用户可在工作台导入一份兼容创作方案，或把当前 Prompt、参数、引用素材和预设导出为文件，解决方案交换、留档和回到某次创作状态的问题。CasRand、KAMIA、画师串工作室的归并由产品内部完成，不让用户面对三源迁移流程。

**用户流程**

```text
[工作台工具栏]
  ↓
[选择导入或导出]
  ├─ 导入 → [选择兼容工作台文件]
  └─ 导出 → [选择导出范围和文件位置]
  ↓
[预览变更]
  ├─ 文件兼容 → [显示 Prompt、参数、引用和冲突摘要]
  ├─ 文件部分兼容 → [允许仅导入可恢复部分]
  └─ 文件不可用 → [不覆盖当前工作台]
  ↓
[用户确认]
  ├─ 导入成功 → [恢复到工作台并保留当前撤销点]
  ├─ 导出成功 → [写出工作台方案文件]
  └─ 写入失败 → [保留当前工作台并提示重试]
```

**状态机**

| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|----------|----------|----------|--------------|
| 待操作 | 用户打开工作台导入导出 | 选择导入/导出 | 工具菜单和说明 |
| 解析中 | 选择导入文件 | 解析完成或失败 | 文件读取进度 |
| 待确认 | 导入预览生成或导出范围已选 | 用户确认/取消 | 变更摘要、引用冲突、导出范围 |
| 导入中 | 用户确认导入 | 成功/失败 | 禁用重复导入 |
| 导出中 | 用户确认导出 | 成功/失败 | 导出进度 |
| 已恢复 | 导入成功 | 用户继续编辑 | 工作台显示恢复结果 |
| 部分兼容 | 文件中有不可恢复字段 | 用户选择继续/取消 | 可恢复内容和跳过项 |

**字段规范**

| 字段名 | 类型 | 是否必填 | 长度限制 | 校验规则 | 错误提示 |
|--------|------|----------|----------|----------|----------|
| 导入文件 | 文件 | 导入必填 | 系统限制 | 必须为兼容工作台或配置文件 | `文件无法导入` |
| 导出文件名 | 文本 | 导出必填 | 1-160 | 去空后非空 | `请输入导出文件名` |
| 导出范围 | 多选 | 导出必填 | - | 至少包含 Prompt 或参数 | `请选择导出内容` |
| 冲突处理 | 枚举 | 导入时按需 | - | 覆盖当前工作台/新建草稿/仅导入参数 | `请选择恢复方式` |

**文案规范**

| 场景 | 文案内容 |
|------|----------|
| 空状态 | `当前工作台还没有内容，可以先导入一份方案。` |
| 加载中 | `正在读取工作台方案...` |
| 操作成功 | `工作台方案已恢复。` |
| 操作失败 | `方案未导入，当前工作台保持不变。` |

| 字段名 | 类型 | 是否必填 | 长度限制 | 校验规则 | 错误提示 |

| 收藏/评分 | 布尔/枚举 | 否 | - | 本地持久化 | `状态保存失败` |

**文案规范**

| 场景 | 文案内容 |
|------|----------|
| 空状态 | `还没有生成结果，先去工作台画一张。` |

## 五、关键体验与信息架构约束

### 1. 用户可见原则

- 产品主语固定为 `Prompt + 生图工作室`，不出现小说章节口径。
- 一级导航固定为 `主页 / 素材库 / 工作台 / 批量产线 / 画廊 / 设置`。
- `Health / 诊断` 不作为主导航、设置页或普通用户流程出现；只在内部校验、日志和开发工具中体现诊断结果。
- 工作台、素材库、批量产线、画廊必须都有真实数据流；不允许以大量空卡片替代业务闭环。

### 2. 数据与来源原则

- 数据归并与索引由产品内部完成，不向用户暴露三源迁移、来源装载或底层存储概念。
- 密钥与私密配置仅本地保存，不写入工作台导出文件。
- 内部素材映射保留 `source` 与快照引用，方便追溯与后续维护，但不要求用户理解来源结构。
- 生成结果必须写回可回溯 metadata；若 metadata 写入策略要求擦除，也要在本地索引中保留生成记录。

### 3. UI 整合原则

- 重做 UI 的目标是减少切换和重复输入，不是把旧页面全部换皮。
- 桌面端工作台优先：素材抽屉、Prompt 装配区、生成预览区同屏协作。
- 批量产线保留 CasRand 高密度配置能力，不强迫其伪装成轻量卡片。
- 辅助工具允许成为二级工具页或抽屉，不抢占日常创作一级导航。

## 六、验收清单

| 验收项 | 验收标准 |
|--------|----------|
| 三源能力内置整合 | 用户无需处理三源迁移流程，素材库、工作台和批量产线直接承接三源核心能力 |
| 素材完整性 | 角色、Outfit、画师串、配方、Tag、过滤规则、参考资产都有归宿 |
| 高级生成不缩水 | 工作台或批量产线可访问现有生成参数、I2I、Vibe、Precise Reference、metadata 控制 |
| 单张闭环 | 从工作台选择素材到生成一张图并写回画廊可完成 |
| 批量闭环 | Config 树、批次控制、暂停/恢复/重试、配置导入导出可完成 |
| 回溯闭环 | 画廊可查看 Prompt 与参数并送回工作台 |
| 辅助工具不丢 | 翻译、分类、拆分、过滤、metadata 排序/批处理、预设均有入口和保存路径 |
| 旧口径清理 | 无小说章节入口，无用户可见 Health 页面 |
