# Prompt Atlas 本地图片提示词查看器设计

## 目标

在 `C:\Users\admin\Downloads\新建文件夹 (3)` 根目录生成一个可双击打开的单文件 HTML。页面展示该目录根目录的 18 张图片；用户点击图片后，可以查看图片中的生成提示词、中文翻译、模型和基础生成参数。

页面只处理根目录图片，不递归纳入 `逍遥西游服务端源码` 子目录的网页素材。原图保持只读，不重编码、不写回元数据。

## 已确认的交互与视觉方向

- 使用缩略图网格作为入口，点击某张图片后打开详情视图。
- 提示词使用真正的独立小标签墙，而不是表格行。
- 每个标签保留原文，并在标签内显示较大的中文翻译；中文是主要阅读层级，不使用难以辨认的小号注释。
- 正向提示词和负向提示词分开显示；分类区域包括质量、角色/外观、服装/身体、动作/画面、风格等，无法可靠判断的标签归入“其他”。
- 权重、LoRA 标记和待确认状态保留在标签上；长标签自动换行，不截断原文或译文。
- 提供按文件名、原文、中文翻译搜索，以及正向/负向切换。
- 元数据缺失时明确显示“未发现提示词”或“模型未记录”，不伪造内容。
- 使用项目已有的中文标签卡设计原则：原始标签始终保留，翻译只作辅助显示，不改变原始 Prompt。

## 数据读取与转换

HTML 内嵌由本地构建步骤提取的数据，不依赖网络、后端或用户配置的 API。

- NovelAI PNG：读取 `Comment` JSON 中的 `prompt`、`uc`、`model_name`、`model_hash`、采样参数等字段。
- ComfyUI PNG：读取 `prompt`/`workflow` JSON，提取实际连接到正向/负向文本节点的内容、基础 checkpoint/UNet、CLIP、VAE、LoRA 和放大模型。
- A1111/Krea 风格参数块：读取 `parameters` 中的提示词、负面提示词、模型和生成参数。
- 没有提示词字段的图片仍展示缩略图，并在详情面板说明元数据缺失。
- 标签解析保留权重语法、LoRA 语法、原始大小写、中文和自定义 token；逗号/换行作为主要分隔依据，完整句子或无法安全拆分的片段作为一个标签保留。
- 翻译使用离线整理的标签翻译数据，不调用项目 API、用户 API、OpenAI-compatible endpoint 或项目凭据。常见标签提供中文；不确定的自定义 token 保留原文并标记“待确认”。

## 文件结构与技术方案

- 交付文件：`提示词查看器.html`，保存于目标图片文件夹根目录。
- 使用原生 HTML、CSS、JavaScript；图片通过同目录相对路径引用，保证双击 HTML 即可打开。
- 提示词数据以 JSON 形式内嵌在 HTML 中，避免额外的 JSON 依赖文件。
- 页面状态仅存在于内存：当前图片、搜索词、正/负向视图和标签筛选不会修改原图或生成额外缓存。
- 不加载外部字体、图标库或网络脚本，保证离线打开；图标使用文字和 CSS，不依赖 Emoji 作为功能图标。

## 异常与兼容处理

- 对损坏、扩展名与真实格式不一致的图片继续显示文件卡片，并标记“无法读取元数据”；例如发现 `.png` 实际是 JPEG 时不改变文件名。
- JSON 解析失败时保留原始元数据摘要，并显示“提示词结构无法解析”，不让单张图片阻塞整个页面。
- 未确认翻译使用明显但不过度的“待确认”状态；原文永远可见。
- 标签墙支持窄屏换行；详情弹窗支持键盘 `Esc` 关闭和可见焦点。

## 验收标准

1. 双击 `提示词查看器.html` 后能看到根目录 18 张图片的缩略图。
2. 点击任意缩略图能打开详情；有元数据的图片显示对应正向/负向提示词和模型，无元数据的图片显示明确缺失状态。
3. 标签以独立小标签呈现；中文字号和对比度足以直接阅读，长中文不会被截断。
4. 原文、中文、权重、分类和待确认状态同时可见，搜索可以命中原文或中文。
5. 页面离线可用，不触发任何网络/API 请求，不修改图片文件。
6. 使用浏览器打开页面并检查至少一张 ComfyUI 图片、一张 NovelAI 图片、一张缺少提示词的图片，以及正向/负向标签切换。
