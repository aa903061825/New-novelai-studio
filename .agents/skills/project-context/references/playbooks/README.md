# Failure Pattern Playbooks

Use playbooks for reusable investigation notes.

Playbooks are clues, not facts. Each playbook should point back to source evidence, test output, command output, or direct inspection.

## Template

```md
# Pattern Name

## Symptom

What was observed.

## Verified Cause

What evidence confirmed the cause.

## Evidence

Source files, tests, command output, or direct inspection notes.

## Prevention Or Verification

How to avoid repeating the failure or verify the fix.
```
